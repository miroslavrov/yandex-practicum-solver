# Яндекс.Документы / Диск — данные и загрузка

Части курса (сертификаты, зачётные документы, отчёты) просят загрузить файл на Яндекс.Диск или заполнить Яндекс.Документ.

## Что запросить у пользователя

- ФИО (как в документах): фамилия, имя, отчество.
- Данные, которые должен содержать документ (школа/вуз, группа, курс, дата — по формулировке задания).
- OAuth-токен Яндекса с правами `cloud_api:disk.write` + `cloud_api:disk.read` (получается на oauth.yandex.ru) или cookie/токен от его сессии — без него API Диска не пустит.

## Загрузка через API Диска

1. `GET https://cloud-api.yandex.net/v1/disk/resources/upload?path=<path>&overwrite=true` с `Authorization: OAuth <token>` → `{href, method}`.
2. `PUT <href>` с телом файла → 201.
3. Публикация (если нужна ссылка): `PUT /v1/disk/resources/publish?path=<path>` → потом `GET /v1/disk/resources?path=<path>` → `public_url`.

Файл для загрузки генерируем сами (docx через python-docx / pdf / md), подставляя ФИО пользователя и данные задания. Ссылку на опубликованный файл вставляем в форму урока (submit_url или поле ответа блока — по типу урока).
