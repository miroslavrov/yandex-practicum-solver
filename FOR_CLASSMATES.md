# Инструкция для студентов — как пройти курс с помощью ИИ-агента

## Что сделать

1. Установи этот скилл своему ИИ-агенту (Devin/другой агент со скиллами): скинь ему ссылку на этот репозиторий и попроси установить как skill (ссылку на этот репозиторий, файл `SKILL.md`).
2. Скажи агенту: «Пройди за меня курс Андроид-разработчик в Яндекс.Практикуме до 100%».

## Что агент у тебя спросит (подготовь заранее)

- **Куки от practicum.yandex.ru** — файл Netscape cookies из твоего браузера (расширение «Get cookies.txt» или DevTools → Application → Cookies → экспорт). Ты должен быть залогинен в Практикуме с купленным курсом.
- **GitHub Personal Access Token** с правами `repo` — чтобы агент вёл проект и открывал PR от твоего имени (создаётся на github.com → Settings → Developer settings → Tokens).
- **Репозиторий для проекта** — название для нового (например, `android-lab`) или ссылка на существующий. Агент спросит видимость: урок требует Private, но для проверки преподавателем удобнее Public.
- **ФИО и данные для документов** — фамилия, имя, отчество (как в зачётке), вуз/группа, если курс просит документы на Яндекс.Диске. Возможно, OAuth-токен Яндекс.Диска.
- **Ник преподавателя на GitHub** (если попросят добавить в коллабораторы) — агент добавит сервисного ревьюера `interactivetextbook` вместе с тобой в настройках репозитория.

## Что будет дальше

Агент сам: пройдёт все уроки/квизы/задачи по API, будет вести проект спринтами через PR (ветка → PR → мёрдж → удаление ветки), оформит README и чек-листы, откроет финальный PR `sprint-12 → review` и сдаст ссылку в форму «Сдать работу». Тебе останется только принять ревью и дождаться зачёта. Все коммиты и PR будут от твоего имени.
